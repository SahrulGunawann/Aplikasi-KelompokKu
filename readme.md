# KelompokKu 📚👥

KelompokKu adalah aplikasi mobile berbasis Ionic Angular yang membantu mahasiswa dan pelajar dalam mengelola kelompok belajar atau kelompok tugas dengan lebih mudah dan terorganisir.

## ✨ Fitur Utama

- Menambahkan data kelompok berdasarkan mata kuliah atau mata pelajaran
- Menampilkan daftar kelompok yang telah dibuat
- Melihat detail kelompok
- Mengedit data kelompok
- Menghapus data kelompok
- Mengelola anggota kelompok
- Menentukan ketua kelompok
- Menambahkan catatan atau keterangan
- Fitur pencarian kelompok
- Penyimpanan data lokal

---

## 🛠️ Teknologi yang Digunakan

- Ionic Framework
- Angular
- TypeScript
- SCSS
- Capacitor
- Ionic Storage / Local Storage

---

## 📱 Tampilan Aplikasi

KelompokKu memiliki desain yang modern, minimalis, dan menggunakan warna-warna fun agar nyaman digunakan oleh mahasiswa dan pelajar.

---

## 🎯 Tujuan Aplikasi

Aplikasi ini dibuat untuk membantu pengguna agar lebih mudah mengingat dan mengelola informasi kelompok belajar, anggota kelompok, dan tugas kelas secara praktis melalui perangkat mobile.
